# Inky

Open source AI writing assistant for macOS. Fix and polish what you write in any app — Slack first — with a one-line explanation for every change, using the AI subscription you already have (Claude Code, Codex, Ollama or an API key).

> Early development. See [docs/SPEC.md](docs/SPEC.md) for the Phase 1 plan and [docs/research](docs/research) for what we've validated.

## Build

```sh
Scripts/build-app.sh
open build/Inky.app
```

Requires macOS 15+, Xcode 26+, and the Accessibility permission.
